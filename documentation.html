Authentication

  -H "Authorization: Bearer <your_api_token>"

Residential Proxy Request

curl -x http://user:pass@gate.proxyvault.com:12321 \
  -U "http://targetsite.com" \
  --proxy-header "X-Proxy-Location: US"
