Frequently Asked Questions

Do I need to configure proxies separately?

No. Web Unblocker handles all proxy selection, rotation, and fingerprint management automatically. You send a URL and receive rendered content — no proxy setup required.

What types of CAPTCHAs can it solve?

Web Unblocker supports reCAPTCHA v2/v3, hCaptcha, Cloudflare challenges, and many custom CAPTCHA implementations. New challenge types are added continuously through our AI engine.

How is pricing calculated?

You are charged per successful request. Failed requests (due to target site being down, invalid URLs, etc.) are not billed. Volume discounts apply on Starter and Enterprise plans.

Can I use Web Unblocker alongside regular proxies?

Yes. Many teams use Web Unblocker for difficult targets and standard proxy products for high-volume, unprotected scraping. Both are managed from the same ProxyVault account.

Does it support JavaScript-heavy sites?

Yes. Web Unblocker includes full headless browser rendering, making it suitable for React, Vue, Angular, and other single-page application frameworks.
